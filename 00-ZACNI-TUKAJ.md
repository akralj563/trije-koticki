# Prvi korak do spletne strani

Ta paket vsebuje projektni brief, izvorno besedilo in navodila za Claude Code. Koda spletne strani še ni izdelana. Delovne oznake v paketu niso ime znamke ali končna javna vsebina.

**Naredi zdaj**

1. Razširi ZIP v novo mapo, kjer želiš hraniti projekt.
2. V VS Code izberi File → Open Folder in odpri mapo, ki neposredno vsebuje CLAUDE.md in mapo docs.
3. Izberi Terminal → New Terminal. Preveri, da terminal kaže to mapo.
4. V običajnem terminalu zaženi `claude`.
5. Odpri 01-PRVI-PROMPT.txt, kopiraj njegovo vsebino in jo pošlji Claudu.
6. Odpri lokalni URL, ki ga Claude izpiše. Če javi napako, ohrani njeno celotno besedilo za nadaljnjo pomoč.

MCP-je lahko preverimo po zagonu osnove. Za prvi korak niso pogoj. Če Node, npm ali Claude niso dosegljivi, nadaljujemo z odpravo konkretne napake, ne z naključnim nameščanjem več orodij.

**Pot do objave**

1. Brief in priprava: potrditi znamko, kontakte, obseg in način urejanja.
2. Lokalni prototip domače strani: preveriti vizualno smer na telefonu in namizju.
3. Podstrani in katalog: dodati potrjene izdelke ter dogovorjene opise. Manjkajočo vsebino voditi ločeno.
4. Fotografije in končna besedila: nadomestiti razvojne vizuale in pregledati trditve ter recepte.
5. Gibanje in SEO: dodati dogovorjene lahke učinke, metapodatke, notranje povezave in sitemap za dejansko domeno.
6. Preverjanje: build, navigacija, kontakt, mobilni prikaz, dostopnost, hitrost, razvojne oznake in nastavitve indeksiranja.
7. GitHub in Vercel: repozitorij, predogled, pregled naročnice in nato produkcijska domena; upoštevati ustrezen paket za komercialno uporabo.
8. Predaja: dogovor o posodobitvah, navodila za urejanje in Search Console.

**Odprta vprašanja**

- Ime znamke in ustvarjalke; domena, logotip, lastne fotografije ter dejanski kontakt.
- Ali bo vsebino urejal izdelovalec strani ali naročnica sama?
- Katere vsebine so dovolj pripravljene za prvo objavo?

Najprej pridobimo delujoč lokalni predogled. Izbor CMS, podrobna izvedba obrazca in produkcijska konfiguracija sledijo odgovorom in dogovorjenemu obsegu.
